# Бот записи (первый продукт для портфолио)

Один файл или целый салон: клиент выбирает услугу, время, пишет имя и телефон —
владелец получает уведомление в Telegram и видит все заявки командой `/bookings`.

## Запуск

1. В Telegram открой **@BotFather**, отправь `/newbot`, придумай имя и юзернейм.
   Скопируй выданный токен.
2. Узнай свой ID у **@userinfobot**.
3. Скопируй `.env.example` → `.env`, вставь токен и свой ID:
   ```
   copy .env.example .env
   ```
4. Установи зависимости и проверь себя:
   ```
   pip install -r requirements.txt
   python bot/selfcheck.py
   ```
5. Запусти:
   ```
   python bot/main.py
   ```
   В терминале появится `Подключено: @твой_бот` и `Бот запущен`.
   **Окно терминала должно быть открыто всё время, пока бот работает** — закрыл окно, бот перестал отвечать.
6. Найди своего бота по юзернейму в Telegram и нажми `/start`.
7. В меню под полем ввода нажми «Записаться» → выбери услугу и время кнопками →
   напиши имя → нажми «Отправить номер». Заявка уйдёт админу.

Остановка: `Ctrl+C` в терминале.

## Подстройка под клиента

В `bot/main.py` вверху:
- `SERVICES` — список услуг (ключ может быть любой латиницей, значение — что видит клиент);
- `SLOTS` — доступные часы записи.

Данные заявок пишутся в `bot/bookings.json`.Удаление файла = очистка заявок.

## Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/start` | клиент | главное меню |
| «Записаться» | клиент | выбрать услугу и время |
| «Отменить» | клиент | прервать запись |
| «Отправить номер» | клиент | номер телефона без ввода |
| `/bookings` | админ | последние 10 заявок |
| `/help` | все | справка |
